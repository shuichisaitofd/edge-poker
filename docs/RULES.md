# 旅館カブ ルール仕様

出典: 元ゲーム https://masudahp.web.fc2.com/vb6/vb6game/card100.html (2026-10-19 取得) と、
プロジェクト指示書。**「確定」= 出典に明記あり / 「暫定」= 出典に記載なし。暫定は実装側の判断であり、
`js/rules.js` 冒頭の `CONFIG` で切り替えられる。**

## 確定(出典に記載あり)

| 項目 | 内容 |
|---|---|
| 使用札 | 4スートの A(1)〜10、計40枚。J/Q/K なし |
| 点数 | 手札の合計の1の位(15 → 5点)。9に近いほど強い |
| 初期配札 | 場に4枚、親に1枚 |
| 賭け | 場の4枚から1枚を選び、賭け点を決める |
| 追加配札 | 場の各札と親に1枚ずつ追加。さらに1枚要求でき、最大3枚 |
| シッピン | A と 4(プレイヤーのみ)。賭け点 ×3 |
| クッピン | A と 9(親のみ)。無条件で親の勝ち。プレイヤーの役も無効 |
| 嵐 | 3枚とも同じ数字。賭け点 ×5。A・3・5・10 は ×10 |
| 順子 | 同スートの連番3枚。賭け点 ×5 |

### 名称の注意
指示書は A+4 を「ミッピン」と記載しているが、出典ページの表記は「**シッピン**」。
画面には出典どおり「シッピン」を表示する(`CONFIG.SHIPPIN_NAME` で変更可)。

## 暫定(出典に記載なし)

| 項目 | 採用した暫定ルール | 設定キー |
|---|---|---|
| 親が3枚目を引く条件 | 2枚の手札が5点以下なら引く。クッピンなら引かない | `DEALER_DRAW_MAX = 5` |
| プレイヤーが3枚目を引ける条件 | 2枚の時に1回だけ、選んだ札へ | — |
| 役の判定対象 | シッピン/クッピンは2枚の手札のみ。嵐・順子は3枚の手札のみ(3枚目を引くとシッピンは消える) | — |
| 倍率の意味 | 純利益 = 賭け金 × 倍率。勝ちは賭け金が戻り、さらに純利益が加わる | `PAYOUT_IS_NET = true` |
| 通常勝ちの倍率 | ×1 | `NORMAL_MULT = 1` |
| 役同士の優先 | クッピン > 嵐 > 順子 > シッピン > 通常。同じ役同士は引き分け | `ROLE_RANK` |
| 引き分け | 賭け金を返却 | `TIE = 'push'` |
| 親の役(嵐/順子)でプレイヤーが負けた時 | 賭け金のみ失う(倍率は適用しない) | — |
| 親の1枚目 | 伏せたまま。公開は勝負時に1枚ずつ | `DEALER_FIRST_FACE_UP = false` |
| 0点 | 通常の点数として扱う(役なし) | — |
| 持ち金 | 初期1,000円。5円未満になったら1,000円に戻して再開 | — |

## 配当の例

賭け金 100円・シッピン勝ち → 返却100 + 純利益300 = 手元に +300円 (合計400円受け取り)
賭け金 100円・通常勝ち → 返却100 + 純利益100
賭け金 100円・引き分け → 100円返却
賭け金 100円・負け → 0円(賭け確定時に控除済み)

## ゲームの目的(ボス戦)
- 親は「あき」。ガソスタに忘れた **4,000円** を持っている。あきの持ち金を0にすればクリア。
- 自分の持ち金は 1,000円 からスタート(簡易シミュレーションでは、堅実に賭ければクリア率6〜7割、強気に賭けると3〜4割)。
- 勝った配当は、あきの残額が上限(残り200円なら最大+200円)。**負けた掛け金はあきの持ち金になる**(お金の総量は変わらない)。
- 持ち金が5円未満になったら BAD END(暗転→「次の日」→あきに焼きまんじゅうを奢ってもらう)。再挑戦で持ち金1,000円・あき4,000円に戻る。
- あきを倒すと GOOD END(「次の日」→あきに焼きまんじゅうをおごる)。クリア回数・最短クリア戦数は戦績シートに保存。

## 演出: 9(カブ)
- 手札が9点になった瞬間(2枚目・3枚目)に「激アツ」予告(赤い画面・点滅・振動)。
- 9点で勝つとパチンコ/スロット風の「大当たり」(虹の背景・リール9-9-9・コイン噴出・「カブ！！」)。タップでスキップ可。

## リセット
- 左上SCOREの戦績シートに「最初からやり直す」(持ち金1,000円・あき4,000円・卓を空に。進行中でも可。戦績は残る)と「戦績を消す」。どちらも2回タップで実行。
